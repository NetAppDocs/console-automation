= Resize an Azure volume and the respective AVS DataStore with Cloud Volumes ONTAP

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/azure/ha/volumes/{workingEnvironmentId}/storage-vms/{svmName}/volumes/{volumeName}/resize-avs-ds`#



Resizes the volume and the respective Azure VMware Solution (AVS) DataStore.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|The system ID


|svmName
|string
|path
|True
a|The SVM name


|volumeName
|link:#VolumeName[VolumeName]
|path
|True
a|The volume name


|===

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|privateCloudName
|string
|True
a|Azure VMware Solution (AVS) private cloud name


|clusterName
|string
|True
a|Private cloud cluster name


|resourceGroup
|string
|True
a|Private cloud resource group name


|dataStoreName
|string
|True
a|Private cloud data store name


|dataStoreSize
|link:#Capacity[Capacity]
|True
a|

|===

```
Status: Default, Default response
```
