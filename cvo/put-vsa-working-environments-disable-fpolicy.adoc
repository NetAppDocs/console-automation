= Disable the FPolicy for ransomware files
:imagesdir: ../media/

[.lead]
Disables the FPolicy for ransomware files, preventing it from monitoring or managing file access related to ransomware detection. Use this endpoint when you need to stop the ransomware-related FPolicy operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/vsa/working-environments/{workingEnvironmentId}/disable-fpolicy`#
