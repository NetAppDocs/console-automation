= Modify user tags for cloud resources
:imagesdir: ../media/

[.lead]
Modifies the user tags for cloud resources in a specific Cloud Volumes ONTAP instance. Use this to update metadata associated with the cloud resources for organization or tracking purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/user-tags`#
