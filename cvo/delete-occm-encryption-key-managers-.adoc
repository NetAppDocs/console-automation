= Delete an existing key manager
:imagesdir: ../media/

[.lead]
Deletes an existing key manager, removing its configuration from the system. Use this to decommission a key manager that is no longer in use.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/occm/encryption/key-managers/{keyManagerId}`#
