= Updates IOPS and throughput for the disks in an existing aggregate. At least one of the parameters is required.

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/gcp/vsa/aggregates/{workingEnvironmentId}/{aggregateName}`#



Updates IOPS and throughput for the disks in an existing aggregate. At least one of the parameters is required.

|===
|Name
|Type

|Required
|Description

|workingEnvironmentId
|string
|path
|True

|aggregateName
|string
|path
|True
a|The aggregate name


|===

|Type
|Required

|integer

|False

|===
