= Retrieve Google Cloud encryption keys for a region
:imagesdir: ../media/

[.lead]
Retrieves Google Cloud encryption keys for a region, providing the necessary keys to manage encryption settings in the specified location.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/metadata/gcp-encryption-keys`#

== Usage notes

Retrieves Google Cloud encryption keys for a specific region.
