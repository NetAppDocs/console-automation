= Update IOPS and throughput for the disks in an existing Cloud Volumes ONTAP aggregate
:imagesdir: ../media/

[.lead]
Updates IOPS and throughput for the disks in an existing aggregate. Use this to adjust performance settings for your Cloud Volumes ONTAP aggregates as needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/gcp/ha/aggregates/{workingEnvironmentId}/{aggregateName}`#

== Usage notes

At least one of the parameters is required.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|The public ID of the system


|aggregateName
|string
|path
|True
a|The name of the aggregate to update


|===

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|iops
|integer
|False
a|New IOPS


|throughput
|integer
|False
a|New throughput


|===


== Error

```
Status: Default, Default response
```
