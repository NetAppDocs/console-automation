= Enable scanning using the file system ID
:imagesdir: ../media/

[.lead]
Enables scanning using the file system ID to initiate file system-level scanning processes. Use this to perform scans based on specific file system identifiers.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/cloud-compliance/fsx/{fileSystemId}/enable-scan`#

== Parameters

[cols=5*,options=header]

|Type
|In
|Required
|Description

|string
|path
|True
