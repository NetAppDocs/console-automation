= Activate snapshot policy assignment for all unprotected read/write volumes
:imagesdir: ../media/

[.lead]
Activates snapshot policy assignment for all unprotected read/write volumes. Use this to ensure snapshot policies are consistently applied across eligible volumes.

== HTTP method and endpoint
