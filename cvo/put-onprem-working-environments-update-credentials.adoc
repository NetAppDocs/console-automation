= Modify the NetApp Console password
:imagesdir: ../media/

[.lead]
Updates the NetApp Console password for an on-premises system, ensuring secure access to the management console. Use this to replace an existing password with a new one when necessary.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/onprem/working-environments/{workingEnvironmentId}/update-credentials`#

== Parameters

[cols=5*,options=header]
|===

|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|===
