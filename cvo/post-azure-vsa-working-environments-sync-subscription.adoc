= Trigger subscription synchronization
:imagesdir: ../media/

[.lead]
Triggers subscription synchronization for all Cloud Volumes ONTAP systems. Use this to ensure subscription data is up-to-date across your deployments.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/azure/vsa/working-environments/sync-subscription`#

== Usage notes

Manually triggers subscription synchronization for all Cloud Volumes ONTAP systems.


== Error

```
Status: Default, Default response
```
