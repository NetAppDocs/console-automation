= Add a NetApp Cloud Central user to NetApp Console

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/users/add-user`#



Adds an existing NetApp Cloud Central user to the NetApp Console.


== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|email
|string
|False
a|User email address


|roleId
|string
|True
a|Role ID of the user


|tenantId
|string
|False
a|Tenant ID of the user


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "email": "string",
  "roleId": "string",
  "tenantId": "string"
}
====
