= Delete a snapshot
:imagesdir: ../media/

[.lead]
Deletes a snapshot manually, removing the specified snapshot from the system. Use this to free up storage space or manage snapshot lifecycle.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/gcp/ha/volumes/{workingEnvironmentId}/{svmName}/{volumeName}/snapshot`#
