= Start a Cloud Volumes ONTAP instance
:imagesdir: ../media/

[.lead]
Starts a Cloud Volumes ONTAP instance, initiating its operation within the cloud environment. Use this to bring the instance online for storage and data management tasks.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/gcp/vsa/working-environments/{workingEnvironmentId}/start`#

== Usage notes

Starts a specific Cloud Volumes ONTAP instance.
