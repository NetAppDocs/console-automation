= Retrieve all iSCSI initiators
:imagesdir: ../media/

[.lead]
Retrieves all iSCSI initiators. Use this to view details about the initiators configured in your system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/fsx/volumes/initiator`#

== Error

```
Status: Default, Default response
```


[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|aliasName
|string
|True
a|Initiator alias


|iqn
|string
|True
a|Initiator IQN


|===


.Example error response

  "aliasName": "string",
  "iqn": "string"
