= Delete FPolicy for ransomware files
:imagesdir: ../media/

[.lead]
Deletes the FPolicy for ransomware files, removing the policy that governs file access and operations related to ransomware detection. Use this to manage or update your security policies effectively.

== HTTP method and endpoint
