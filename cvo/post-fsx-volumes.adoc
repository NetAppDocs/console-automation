= Create a new volume

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/fsx/volumes`#



Creates a new volume.

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|awsTags

|True

|shareInfo

|size
