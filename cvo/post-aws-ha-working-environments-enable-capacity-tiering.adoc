= Enable capacity tiering
:imagesdir: ../media/

[.lead]
Enables capacity tiering, configuring the system to offload inactive data to a capacity tier. Use this to optimize storage utilization and reduce costs.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/enable-capacity-tiering`#

a|

|===
