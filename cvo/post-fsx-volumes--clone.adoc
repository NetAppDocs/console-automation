= Clone a volume
:imagesdir: ../media/

[.lead]
Creates a clone of an existing volume. Use this to replicate volume data for testing or development purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/fsx/volumes/{fileSystemId}/{svmName}/{volumeName}/clone`#

== Usage notes

Clones an existing volume.

|Description

a|

a|
