= Disable the FPolicy for ransomware files
:imagesdir: ../media/

[.lead]
Disables the FPolicy for ransomware files, stopping the policy from monitoring or acting on file access related to ransomware detection. Use this endpoint when you need to suspend ransomware-related file screening.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/disable-fpolicy`#
