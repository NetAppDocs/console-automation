= Retrieve S3 buckets policy status and tiering level
:imagesdir: ../media/

[.lead]
Retrieves the S3 buckets policy status and tiering level. Use this to monitor bucket configurations and tiering settings in your cloud environment.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/metadata/get-buckets-application-info`#

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|buckets
|array[string]
|True
a|

|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "buckets": [
    "string"
  ]
}
====
