= Retrieve Azure VMware Solution cluster hosts
:imagesdir: ../media/

[.lead]
Retrieves Azure VMware Solution cluster hosts for the existing subscription. Use this to view the hosts available within your subscription.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/resourceGroups/{resourceGroupName}/avs-private-clouds/{privateCloudName}/clusters/{clusterName}/hosts`#
