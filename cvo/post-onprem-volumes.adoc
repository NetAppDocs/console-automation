= Create a new volume

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/onprem/volumes`#



Creates a new volume.


== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|aggregateName
|string
|False
a|Aggregate in which to create the volume


|enableCompression
|boolean
|True
a|Enable compression on the volume


|enableDeduplication
|boolean
|True
a|Enable deduplication on the volume


|enableThinProvisioning
|boolean
|True
a|Enable thin provisioning on the volume


|exportPolicyInfo
|link:#ExportPolicyInfo[ExportPolicyInfo]
|False
a|

|flexGroupVolumeInfo
|link:#FlexGroupVolumeInfo[FlexGroupVolumeInfo]
|False
a|

|initialSize
|link:#Capacity[Capacity]
|False
a|

|iscsiInfo
|link:#CreateIscsiInfoRequest[CreateIscsiInfoRequest]
|False
a|

|name
|string
|False
a|Volume name, unique within the SVM


|shareInfo
|link:#CreateCifsShareInfoRequest[CreateCifsShareInfoRequest]
|False
a|

|size
|link:#PositiveCapacity[PositiveCapacity]
|True
a|

|snapshotPolicyName
|string
|True
a|Snapshot policy name


|svmName
|string
|True
a|SVM name


|syncToS3
|boolean
|True
a|Add a cloud sync relationship


|volumeTags
|array[link:#VolumeTags[VolumeTags]]
|True
a|Optionally, provide key-value pairs with which to tag the ONTAP volume using the App Template service.


|workingEnvironmentId
|string
|True
a|Target system ID


|===


== Error

```
Status: Default, Default response
```
