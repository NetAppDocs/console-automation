= Retrieve Azure availability zones by region
:imagesdir: ../media/

[.lead]
Retrieves Azure availability zones by region. Use this to identify the zones available in a specified Azure region for resource planning or deployment.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/vsa/metadata/availability-zones`#
