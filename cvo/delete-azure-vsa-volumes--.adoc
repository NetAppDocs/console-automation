= Delete an existing volume
:imagesdir: ../media/

[.lead]
Deletes an existing volume, removing the specified volume and its associated data from the system. Use this to free up storage space or manage resources effectively.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/azure/vsa/volumes/{workingEnvironmentId}/{svmName}/{volumeName}`#
