= Retrieve all tag names
:imagesdir: ../media/

[.lead]
Retrieves all tag names. Use this to view the available tags for resource identification or organization.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/vsa/metadata/tag-keys`#

== Usage notes

Retrieves all of the tag names.
