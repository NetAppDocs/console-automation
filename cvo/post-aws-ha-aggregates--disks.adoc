= Add disks to an existing aggregate
:imagesdir: ../media/

[.lead]
Adds disks to an existing aggregate, expanding its capacity to accommodate more data. Use this to manage storage growth or optimize aggregate performance.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/aws/ha/aggregates/{workingEnvironmentId}/{aggregateName}/disks`#
