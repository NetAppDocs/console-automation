= Check for non-persistent locks
:imagesdir: ../media/

[.lead]
Checks for non-persistent locks held on CIFS sessions, providing information about locks that may impact file access or operations. Use this to identify and manage potential conflicts in CIFS environments.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}/cifs-locks-exist`#
