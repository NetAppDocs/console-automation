= Validate the credentials for an FSx system
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/fsx/working-environments/validate-credentials`#



Validates the provided credentials for an existing FSx system.


== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|backup
|link:#SvmCredentials[SvmCredentials]
|False
a|

|default
|link:#SvmCredentials[SvmCredentials]
|False
a|

|ip
|string
|True
a|

|weId
|string
|False
a|

|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "backup": {
    "password": "string",
    "userName": "string"
  },
  "default": {
    "password": "string",
    "userName": "string"
  },
  "ip": "string",
  "weId": "string"
}
====
