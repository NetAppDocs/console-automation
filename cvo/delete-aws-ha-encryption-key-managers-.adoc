= Delete a key manager from a system
:imagesdir: ../media/

[.lead]
Deletes a key manager from the Cloud Volumes ONTAP system. Use this to remove an unused or decommissioned key manager.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/aws/ha/encryption/{workingEnvironmentId}/key-managers/{keyManagerIp}`#
