= Retrieve the intercluster LIFs
:imagesdir: ../media/

[.lead]
Retrieves the intercluster LIFs used in a cluster peering relationship. Use this to view the network interfaces facilitating communication between peer clusters.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/replication/intercluster-lifs`#
