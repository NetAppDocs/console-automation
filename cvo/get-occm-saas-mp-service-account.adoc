= Retrieve current SaaS marketplace accounts and subscriptions
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/occm/saas-mp-service/account`#



Retrieves the current SaaS marketplace account and subscriptions.


== Error

```
Status: Default, Default response
```


[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|awsSubscriptions
|array[link:#SubscriptionResponse[SubscriptionResponse]]
|True
a|AWS subscriptions


|azureSubscriptions
|array[link:#SubscriptionResponse[SubscriptionResponse]]
|True
a|Azure subscriptions


|cloudAccounts
|array[link:#CloudAccountResponse[CloudAccountResponse]]
|True
a|Cloud accounts


|eligibleBycapLicenseCvoPackages
|array[string]
|True
a|Eligible ByCap license Cloud Volumes ONTAP packages


|eligibleForFreeTrialAws
|boolean
|True
a|Indicates eligibility for an AWS free trial


|eligibleForFreeTrialAzure
|boolean
|True
a|Indicates eligibility for an Azure free trial


|eligibleForFreeTrialGcp
|boolean
|True
a|Indicates eligibility for a Google Cloud free trial


|gcpSubscriptions
|array[link:#SubscriptionResponse[SubscriptionResponse]]
|True
a|Gcp Subscriptions


|===
