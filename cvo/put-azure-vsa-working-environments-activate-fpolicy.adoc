= Activate the FPolicy for ransomware files
:imagesdir: ../media/

[.lead]
Activates the FPolicy for ransomware files, enabling the detection and management of potentially malicious file activity. Use this to enhance security by monitoring and responding to ransomware threats.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/activate-fpolicy`#
