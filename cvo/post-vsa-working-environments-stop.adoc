= Stop a specific Cloud Volumes ONTAP instance
:imagesdir: ../media/

[.lead]
Stops a specific Cloud Volumes ONTAP instance. Use this to halt operations on the instance when needed for maintenance or other administrative tasks.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/working-environments/{workingEnvironmentId}/stop`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|string
|path
|True
a|

|takeSnapshots
|boolean

|False
a|
