= Update the NetApp Console password
:imagesdir: ../media/

[.lead]
Updates the NetApp Console password for a specific Cloud Volumes ONTAP system. Use this endpoint to change the password and maintain secure access to the console.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/update-credentials`#

== Parameters

|Required
|Description

|string

|True
a|

|===
