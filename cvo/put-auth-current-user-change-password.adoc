= Update the user password
:imagesdir: ../media/

[.lead]
Updates the password for the current user. Use this to change your password when required for security or account management purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/auth/current-user/change-password`#

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|newPassword
|string
|False
a|User's new password


|oldPassword
|string
|True
a|User's current password


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "newPassword": "string",
  "oldPassword": "string"
}
====

== Error

```
Status: Default, Default response
```
