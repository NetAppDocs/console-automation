= Delete an SVM
:imagesdir: ../media/

[.lead]
Deletes an SVM, removing the specified storage virtual machine from the system. Use this to decommission an SVM that is no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/svm/{svmName}`#
