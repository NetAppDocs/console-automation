= Retrieve quotes for a new volume

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/gcp/ha/volumes/quote`#



Retrieves quotes for a new volume. Returns the resource quote required for the requested volume.


== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|aggregateName
|string
|False
a|Optionally choose in which aggregate to create the volume


|capacityTier
|string
|False
a|Capacity tier


|enableThinProvisioning
|boolean
|True
a|Enable thin provisioning on the volume


|initialSize
|link:#Capacity[Capacity]
|False
a|

|iops
|integer
|False
a|Provisioned IOPS


|isReplicationFlow
|boolean
|True
a|Is replication flow


|name
|string
|False
a|Volume name, unique within the SVM


|providerVolumeType
|string
|False
a|Provider volume type


|size
|link:#PositiveCapacity[PositiveCapacity]
|True
a|

|svmName
|string
|True
a|SVM name


|throughput
|integer
|False
a|Provisioned throughput


|tieringPolicy
|string
|False
a|Tiering policy


|verifyNameUniqueness
|boolean
|True
a|Verify volume name uniqueness within the SVM


|workingEnvironmentId
|string
|True
a|Cloud Volumes ONTAP system ID


|===
