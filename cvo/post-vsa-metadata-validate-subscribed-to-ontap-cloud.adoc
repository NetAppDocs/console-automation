= Comfirm that the current user is subscribed

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/metadata/validate-subscribed-to-ontap-cloud`#



Validates that the current user is subscribed to the Cloud Volumes ONTAP product in Amazon marketplace.
