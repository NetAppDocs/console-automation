= Retrieve Google Cloud networks and subnetworks
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/metadata/vpcs`#



Retrieves Google Cloud networks and subnetworks where a Cloud Volumes ONTAP system can be created.

[cols=5*,options=header]

|Name
|Type
|In
|Required
|Description

|region
|string
|query
|False

|project
|string
|query
|False
a|

|===
