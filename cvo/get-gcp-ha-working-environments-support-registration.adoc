= Retrieve the support registration status
:imagesdir: ../media/

[.lead]
Retrieves the support registration status of a Cloud Volumes ONTAP system, providing information about its current registration state. Use this to confirm whether the system is successfully registered for support.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/support-registration`#
