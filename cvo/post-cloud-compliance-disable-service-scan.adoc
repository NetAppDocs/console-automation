= Disable scanning using the service ID
:imagesdir: ../media/

[.lead]
Disables scanning using the service ID, stopping the scanning process for the specified service. Use this endpoint when you need to halt scanning operations for a particular service instance.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/cloud-compliance/{serviceId}/disable-service-scan`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|serviceId
|string
|path
|True

|===
