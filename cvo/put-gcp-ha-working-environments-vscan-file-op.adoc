= Update the default Vscan file operation profile
:imagesdir: ../media/

[.lead]
Updates the default Vscan file operation profile. Use this to modify the settings applied to CIFS shares, ensuring changes affect only the writes-only mode.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/vscan-file-op`#

== Usage notes

Profiles on existing CIFS shares will change only on writes-only mode.
