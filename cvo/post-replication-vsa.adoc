= Create a new replication for a Cloud Volumes ONTAP system

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/replication/vsa`#



Creates a new replication to a Cloud Volumes ONTAP system.


== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|replicationRequest
|link:#ReplicationRequest[ReplicationRequest]
|True
a|

|replicationVolume
|link:#VsaVolumeRequest[VsaVolumeRequest]
|True
a|

|===


== Error

```
Status: Default, Default response
```
