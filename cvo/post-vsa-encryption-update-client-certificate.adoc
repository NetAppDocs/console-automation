= Update the client certificate
:imagesdir: ../media/

[.lead]
Updates the client certificate on the Cloud Volumes ONTAP system. Use this to replace an existing certificate when required for secure client communication.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/encryption/{workingEnvironmentId}/update-client-certificate`#
