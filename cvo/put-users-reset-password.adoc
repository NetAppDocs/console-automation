= Reset the password
:imagesdir: ../media/

[.lead]
Resets the password for the specified user. Use this endpoint to update a user's password when access credentials need to be changed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/users/{userId}/reset-password`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|string
|path
|True
a|

|===
