= Activate snapshot policy assignment
:imagesdir: ../media/

[.lead]
Activates snapshot policy assignment for all unprotected read/write volumes. Use this to ensure that snapshot policies are applied to volumes currently lacking protection.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}/activate-snapshot-policy`#
