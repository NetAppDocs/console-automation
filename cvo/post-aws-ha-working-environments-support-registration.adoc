= Register a system with NetApp
:imagesdir: ../media/

[.lead]
Registers a Cloud Volumes ONTAP system with NetApp, enabling system management and monitoring through NetApp services. Use this to integrate the system with NetApp tools for optimized operations and support.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/support-registration`#
