= Update the AutoSupport configuration
:imagesdir: ../media/

[.lead]
Updates the AutoSupport configuration, applying changes to the settings that control automated support and diagnostic data collection. Use this to customize the configuration based on your support requirements.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/occm/asup`#

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|enabled
|boolean
|True
a|

|schedule
|link:#AsupSchedule[AsupSchedule]
|False
a|

|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "enabled": false,
  "schedule": {
    "interval": {
      "unit": "string"
    }
  }
}
====

== Error

```
Status: Default, Default response
```
