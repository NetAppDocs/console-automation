= Create a snapshot
:imagesdir: ../media/

[.lead]
Creates a snapshot manually. Use this to capture the state of a resource at a specific point in time for backup or recovery purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/fsx/volumes/{fileSystemId}/{svmName}/{volumeName}/snapshot`#
