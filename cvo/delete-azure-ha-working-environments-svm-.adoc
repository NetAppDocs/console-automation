= Delete an SVM
:imagesdir: ../media/

[.lead]
Deletes an SVM, removing the storage virtual machine and its associated resources. Use this to decommission an SVM that is no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}/svm/{svmName}`#
