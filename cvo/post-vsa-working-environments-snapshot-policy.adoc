= Create a snapshot policy
:imagesdir: ../media/

[.lead]
Creates a snapshot policy, defining the rules and schedules for automatically capturing snapshots of data. Use this to manage data protection and recovery strategies effectively.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/working-environments/{workingEnvironmentId}/snapshot-policy`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|===

|===
|Name
|Type
|Required
|Description

|schedules
|array[link:#SnapshotPolicyScheduleRequest[SnapshotPolicyScheduleRequest]]
|True
a|Snapshot policy schedules


|snapshotPolicyName
|string

a|Snapshot policy name


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "schedules": [
    {
      "retention": 0,
      "scheduleType": "string"
    }
  ],
  "snapshotPolicyName": "string"
}
====
