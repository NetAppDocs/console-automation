= Retrieve route tables per VPC and their subnet associations
:imagesdir: ../media/

[.lead]
Retrieves route tables for a specified VPC and their associated subnets. Use this to examine the network configurations and subnet relationships within the VPC.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/aws/ha/metadata/route-tables`#

== Usage notes

Retrieves route tables per VPC and their subnet associations.
