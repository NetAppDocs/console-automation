= Retrieve the volume count
:imagesdir: ../media/

[.lead]
Retrieves the volume count. Use this to determine the total number of volumes in the system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/fsx/volumes/{fileSystemId}/count`#

|Type
