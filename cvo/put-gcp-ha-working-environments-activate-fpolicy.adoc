= Activate FPolicy for ransomware files
:imagesdir: ../media/

[.lead]
Activates the FPolicy for ransomware files to enable file screening and detection for potential ransomware threats. Use this to help protect your data against unauthorized encryption or malicious file activity.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/activate-fpolicy`#
