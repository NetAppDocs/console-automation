= Retrieves a representation of the current user with the associated roles.

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/auth/v4/current-user`#



Retrieves a representation of the current user with the associated roles.


== Error

```
Status: Default, Default response
```

|email
