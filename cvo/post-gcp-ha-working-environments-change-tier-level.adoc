= Update the tier level
:imagesdir: ../media/

[.lead]
Updates the tier level for storage resources. Use this to adjust the performance or cost characteristics of the storage tier.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/change-tier-level`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|===
