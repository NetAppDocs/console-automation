= Retrieve a list of upgrade versions
:imagesdir: ../media/

[.lead]
Retrieves a list of versions to which this Cloud Volumes ONTAP system can be upgraded. Use this to determine the available upgrade options for your system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/occm-provided-upgrade-versions`#
