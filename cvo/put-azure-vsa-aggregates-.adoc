= Update IOPS and throughput for disks in an existing aggregate (single-node)
:imagesdir: ../media/

[.lead]
Updates IOPS and throughput for disks in an existing aggregate. Use this to adjust performance settings for the aggregate as needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/azure/vsa/aggregates/{workingEnvironmentId}/{aggregateName}`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|aggregateName
|string
|path
|True
a|

|===

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|iops
|integer
|True
a|New IOPS


|throughput
|integer
|True
a|New throughput


|===


.Example request
