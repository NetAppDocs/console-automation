= Retrieve the eligibility support status of a system
:imagesdir: ../media/

[.lead]
Retrieves the eligibility support status of a Cloud Volumes ONTAP system. Use this to determine whether a system meets the requirements for support or registration.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/update-eligibility`#

== Usage notes

Valid values are NSS_NOT_VALID, NOT_REGISTERED, IPA_PROBLEM, VALID, NSS_NOT_EXISTS, LICENSE_EXPIRED.
