= Delete the CIFS configuration for a system
:imagesdir: ../media/

[.lead]
Deletes the CIFS configuration of an existing Cloud Volumes ONTAP system. Use this to remove an outdated or unnecessary CIFS configuration from the system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}/delete-cifs`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|===
