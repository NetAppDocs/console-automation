= Update the default Vscan file operation profile
:imagesdir: ../media/

[.lead]
Updates the default Vscan file operation profile. Use this to modify how file operations are scanned for CIFS shares, ensuring changes apply to writes-only mode.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/vsa/working-environments/{workingEnvironmentId}/vscan-file-op`#

== Usage notes

Profiles on existing CIFS shares will change only on writes-only mode.
