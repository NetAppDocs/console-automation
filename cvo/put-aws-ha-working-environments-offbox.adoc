= Activate an off-box configuration
:imagesdir: ../media/

[.lead]
Activates an off-box configuration to initiate the use of external settings for system operations. Use this to apply configurations stored outside the primary system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/offbox`#
