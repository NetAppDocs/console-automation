= Disable on-premises scanning
:imagesdir: ../media/

[.lead]
Disables on-premises scanning to stop the scanning of local resources for potential issues or configuration changes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/cloud-compliance/{workingEnvironmentId}/disable-onprem-scan`#
