= Update the tier level
:imagesdir: ../media/

[.lead]
Updates the tier level, modifying the storage tier associated with a specific resource. Use this to optimize storage performance or cost based on your workload requirements.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/gcp/vsa/working-environments/{workingEnvironmentId}/change-tier-level`#
