= Validate an active internet connection
:imagesdir: ../media/

[.lead]
Validates an active internet connection, ensuring the NetApp Console can access online resources. Use this to confirm connectivity for operations requiring internet access.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/occm/setup/validate/connectivity`#

== Usage notes

Validates that the NetApp Console has an active internet connection.


== Error

```
Status: Default, Default response
```
