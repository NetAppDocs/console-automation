= Set the instance type
:imagesdir: ../media/

[.lead]
Sets the instance type of a specific Cloud Volumes ONTAP system. Use this to configure the system for a different instance type.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/gcp/vsa/working-environments/{workingEnvironmentId}/license-instance-type`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|===

[cols=4*,options=header]
|===

|Type

|True

|licenseType
|string
