= Perform a complete image update

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/working-environments/{workingEnvironmentId}/update-image`#



Performs a complete image update operation on the single node of the specified Cloud Volumes ONTAP system.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|===

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|updateParameter
|string
|True
a|Parameter specific to the specified update type. External file URL or the NetApp Console provided image name.


|updateType
|string
|True
a|System update type. System updates can be performed by providing either an external URL that ONTAP will use to download the image file or a name of an image provided by the NetApp Console.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "updateParameter": "string",
  "updateType": "string"
}
====

== Error

```
Status: Default, Default response
```
