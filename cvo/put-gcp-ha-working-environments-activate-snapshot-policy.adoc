= Activate snapshot policy assignment for unprotected read/write volumes
:imagesdir: ../media/

[.lead]
Activates snapshot policy assignment for unprotected read/write volumes. Use this to ensure snapshot policies are applied consistently across these volumes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/activate-snapshot-policy`#

== Usage notes

Activates snapshot policy assignment for all unprotected read/write volumes.
