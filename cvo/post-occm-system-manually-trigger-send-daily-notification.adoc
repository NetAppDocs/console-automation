= Trigger sending daily notifications
:imagesdir: ../media/

[.lead]
Triggers the sending of daily notifications manually. Use this endpoint to initiate notifications without waiting for the scheduled daily process.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/occm/system/manually-trigger-send-daily-notification`#

== Usage notes

Triggers daily notification sending manually.

```
Status: Default, Default response
```
