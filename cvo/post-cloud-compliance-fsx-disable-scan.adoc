= Disable scanning using the file system ID
:imagesdir: ../media/

[.lead]
Disables scanning for a specified file system, preventing further scan operations on the associated file system ID. Use this to stop scans that are no longer needed or to manage scanning activities effectively.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/cloud-compliance/fsx/{fileSystemId}/disable-scan`#

== Usage notes

Disables scanning using the file system ID.
