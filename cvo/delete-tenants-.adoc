= Delete an existing tenant
:imagesdir: ../media/

[.lead]
Deletes an existing tenant. Use this to remove tenant configurations when they are no longer needed and no systems are associated with the tenant.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/tenants/{tenantId}`#

== Usage notes

It is not possible to delete a tenant over which systems exist.
