= Retrieve AWS user key pairs by region
:imagesdir: ../media/

[.lead]
Retrieves AWS user key pairs for a specific region. Use this to view the available key pairs associated with your AWS account in the specified region.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/aws/ha/metadata/key-pairs`#
