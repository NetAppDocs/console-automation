= Retrieve system ONTAP savings
:imagesdir: ../media/

[.lead]
Retrieves system ONTAP savings, providing details about storage efficiency and space utilization. Use this to evaluate the effectiveness of storage optimization strategies.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/vsa/working-environments/{workingEnvironmentId}/ontap-saving`#
