= Delete a snapshot
:imagesdir: ../media/

[.lead]
Deletes a snapshot manually. Use this to remove snapshots that are no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/onprem/volumes/{workingEnvironmentId}/{svmName}/{volumeName}/snapshot`#
