= Retrieve the CIFS configuration for a system
:imagesdir: ../media/

[.lead]
Retrieves the CIFS configuration for an existing Cloud Volumes ONTAP system, providing details about the current CIFS setup and settings. Use this to verify or review CIFS configuration parameters for a specific system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/cifs`#

== Parameters

[cols=5*,options=header]

|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

a|
