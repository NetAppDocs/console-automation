= Update the NetApp Console
:imagesdir: ../media/

[.lead]
Updates the NetApp Console to the specified version. Use this to ensure you are running the latest supported version for improved features and stability.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/occm/system/update`#

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|date
|integer
|True
a|

|name
|string
|True
a|

|releaseNumber
|integer
|True
a|

|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "date": 0,
  "name": "string",
  "releaseNumber": 0
}
====

== Error

```
Status: Default, Default response
```
