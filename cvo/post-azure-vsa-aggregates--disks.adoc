= Add disks to an aggregate
:imagesdir: ../media/

[.lead]
Adds disks to an existing aggregate. Use this to increase the storage capacity of the aggregate.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/azure/vsa/aggregates/{workingEnvironmentId}/{aggregateName}/disks`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|aggregateName
|string
|path
|True
a|

|===
