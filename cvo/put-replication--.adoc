= Modify a SnapMirror replication relationship
:imagesdir: ../media/

[.lead]
Updates a SnapMirror replication relationship. Use this to adjust the configuration or behavior of the relationship as needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/replication/{workingEnvironmentId}/{destinationSvmName}/{destinationVolumeName}`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|destinationSvmName
|string
|path
|True
a|

|destinationVolumeName
|string
|path
|True
a|

|===

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|maxTransferRate
|integer
|False
a|New maximum transfer rate limit (KB/s). Use 0 for no limit, otherwise use a number between 1024 and 2,147,482,624.


|schedule
|string
|False
a|New replication schedule name


|===
