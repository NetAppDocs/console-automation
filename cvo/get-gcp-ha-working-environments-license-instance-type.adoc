= Retrieve all license types for a system
:imagesdir: ../media/

[.lead]
Retrieves all license types and their associated instance types for a specific Cloud Volumes ONTAP instance. Use this to view the available licensing options for the instance.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/license-instance-type`#
