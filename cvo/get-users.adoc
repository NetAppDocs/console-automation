= Retrieve all users

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/users`#



Retrieves all users visible to the current user.


== Error

```
Status: Default, Default response
```

|Name
|Type
|Required
|Description

|publicId
|string
|True
a|User public ID


|assignedWorkingEnvironments
|array[string]
|True
a|List of public IDs for all of the systems visible to the user

|string
|True
a|The first name of the user


|lastName
|string
|True
a|The last name of the user


|email
|string
|True
a|The email address of the user


|roleId

|string
