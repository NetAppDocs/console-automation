= Retrieve all users
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/users`#



Retrieves all users visible to the current user.


== Error

```
Status: Default, Default response
```


[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|assignedWorkingEnvironments
|array[string]
|True
a|List of public IDs for all of the systems visible to the user


|azureCredentials
|link:#AzureCredentials[AzureCredentials]
|False
a|

|cloudSyncLicenseInformation
|link:#CloudSyncLicenseInformation[CloudSyncLicenseInformation]
|False
a|

|createdWorkingEnvironments
|array[link:#UserWorkingEnvironmentResponse[UserWorkingEnvironmentResponse]]
|True
a|List of all systems created by the user


|email
|string
|True
a|The email address of the user


|firstName
|string
|True
a|The first name of the user


|isLdap
|boolean
|True
a|Indicates whether the user is an LDAP user


|lastName
|string
|True
a|The last name of the user


|ldapUserName
|string
|True
a|The LDAP user name


|notificationsOptIn
|boolean
|True
a|Notification opt-in


|permissions
|array[string]
|True
a|Permissions


|publicId
|string
|True
a|User public ID


|roleId
|string
|True
a|Role ID of the user


|tenantId
|string
|True
a|Tenant ID of the user


|===
