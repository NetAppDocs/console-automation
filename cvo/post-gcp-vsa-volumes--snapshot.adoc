= Create a snapshot
:imagesdir: ../media/

[.lead]
Creates a snapshot manually, providing a point-in-time copy of data for backup or recovery purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/gcp/vsa/volumes/{workingEnvironmentId}/{svmName}/{volumeName}/snapshot`#

[cols=5*,options=header]

|Name
|Type

|Required
|Description

|workingEnvironmentId
|string
|path

a|

|svmName
|string
|path

a|

|===
