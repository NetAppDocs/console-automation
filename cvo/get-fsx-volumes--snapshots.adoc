= Retrieve a list of snapshot descriptions for a volume
:imagesdir: ../media/

[.lead]
Retrieves a list of snapshot descriptions for a volume. Use this to review the snapshots available for the specified volume.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/fsx/volumes/{fileSystemId}/{svmName}/{volumeName}/snapshots`#

== Usage notes

Returns a list of snapshot descriptions for the volume.
