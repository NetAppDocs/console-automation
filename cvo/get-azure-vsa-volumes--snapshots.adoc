= Retrieve a list of volume snapshot descriptions
:imagesdir: ../media/

[.lead]
Retrieves a list of volume snapshot descriptions for a Cloud Volumes ONTAP (CVO) volume. Use this to view the available snapshots and their metadata for the specified volume.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/vsa/volumes/{workingEnvironmentId}/{svmName}/{volumeName}/snapshots`#

== Usage notes

Returns a list of snapshot descriptions for the volume.
