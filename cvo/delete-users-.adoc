= Delete an existing user
:imagesdir: ../media/

[.lead]
Deletes an existing user. Use this to manage user accounts by removing unnecessary or outdated users from the system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/users/{userId}`#

== Usage notes

It is not possible to delete a user that has created existing systems. It is not possible to delete the logged in user.
