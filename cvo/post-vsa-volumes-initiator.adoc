= Add an iSCSI initiator
:imagesdir: ../media/

[.lead]
Creates an iSCSI initiator, establishing connectivity for iSCSI storage operations. Use this to configure access for iSCSI clients to storage resources.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/volumes/initiator`#

== Usage notes

Adds an iSCSI initiator.


== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|aliasName
|string
|True
a|Initiator alias


|iqn
|string
|True
a|Initiator IQN


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "aliasName": "string",
  "iqn": "string"
}
====

== Error

```
Status: Default, Default response
```
