= Disable monitoring
:imagesdir: ../media/

[.lead]
Disables monitoring, stopping the collection of metrics and performance data. Use this to pause monitoring activities as needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/monitoring/{workingEnvironmentId}/disable-monitoring`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|string
|path
|True
