= Create a new FlexCache volume for an FSx system

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/flexcache/fsx`#



Creates a new FlexCache volume in an FSx system.


== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|cacheVolumePercentage
|integer
|True
a|FlexCache volume percentage


|destinationIpSpace
|string
|False
a|Destination IPspace


|destinationSvmName
|string
|True
a|Destination SVM name


|destinationWorkingEnvironmentId
|string
|True
a|Destination system ID


|nameForSingleVolume
|string
|False
a|FlexCache volume name for a single volume


|namePrefix
|string
|False
a|FlexCache name prefix


|nameSuffix
|string
|False
a|FlexCache name suffix


|replicateNfsCifsShares
|boolean
|True
a|Replicate NFS and CIFS shares as source volume


|sourceIpSpace
|string
|False
a|Source IPspace


|sourceSvmName
|string
|True
a|Source SVM name


|sourceVolumes
|array[string]
|True
a|Names of source volumes


|sourceWorkingEnvironmentId
|string
|True
a|Source system ID


|===


== Error

```
Status: Default, Default response
```
