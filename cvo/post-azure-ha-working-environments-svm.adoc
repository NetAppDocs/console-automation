= Create a new SVM
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}/svm`#



Creates a new SVM.

|Name
|Type
|In
|Required
|Description

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|mgmtLif
|boolean
|True

|rootVolumeAggregate
|string
|False
a|Root volume aggregate name


|svmName
|string
|False
a|

|svmPassword
|link:#AzureSvmPassword[AzureSvmPassword]
|False

|===
