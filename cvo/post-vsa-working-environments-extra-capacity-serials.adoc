= Register extra capacity serial numbers
:imagesdir: ../media/

[.lead]
Registers extra capacity serial numbers to add additional capacity to your system. Use this to ensure the system can utilize the registered capacity for storage operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/working-environments/{workingEnvironmentId}/extra-capacity-serials`#

== Usage notes

Registers an extra capacity serial number.
