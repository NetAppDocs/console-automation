= Start a Cloud Volumes ONTAP instance
:imagesdir: ../media/

[.lead]
Starts a specific Cloud Volumes ONTAP instance, making it operational and ready to handle storage workloads. Use this endpoint to initiate the instance after configuration or maintenance activities.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}/start`#
