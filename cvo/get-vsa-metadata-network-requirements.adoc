= Retrieve the minimum number of required IP addresses
:imagesdir: ../media/

[.lead]
Retrieves the minimum number of required IP addresses for a single Cloud Volumes ONTAP system, HA node, and HA mediator. Use this to determine the IP address requirements for deploying or configuring these systems.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/vsa/metadata/network-requirements`#

== Error

```
Status: Default, Default response
```

|Name
|Type
|Required
|Description

|integer
|False
a|

|haNodeMinimumRequiredIps
|integer
|False
a|

|nonHaNodeMinimumRequiredIps
|integer
|True
a|

|===
