= Update the tier level
:imagesdir: ../media/

[.lead]
Updates the tier level for a Cloud Volumes ONTAP resource. Use this to adjust the storage tier configuration based on your performance or cost requirements.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/change-tier-level`#
