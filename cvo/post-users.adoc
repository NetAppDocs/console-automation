= Create a new user

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/users`#



Creates a new user.

|===
|Name
|Type
|Required
|Description

|firstName
|string
|False

|isLdap
|boolean
|True

|lastName
|string
|False

|ldapUserName
|string
|False
a|The LDAP user name


|notificationsOptIn
|boolean
|False

|password
|string
|False
a|User password


|roleId
|string
|True

|s3Bucket
|string
|False
a|The AWS S3 bucket of the user


|secretKey
|string
|False
a|The AWS secret key of the user


|tenantId
|string
|False
a|Tenant ID of the user
