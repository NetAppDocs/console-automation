= Update extra capacity serial numbers
:imagesdir: ../media/

[.lead]
Updates an extra capacity license serial number to modify the serial number associated with the extra capacity license. Use this to ensure the correct license information is applied for your configuration.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/extra-capacity-serials`#
