= Enable capacity tiering
:imagesdir: ../media/

[.lead]
Enables capacity tiering to optimize storage usage by automatically moving inactive data to a lower-cost storage tier. Use this to improve cost efficiency while maintaining access to data when needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/enable-capacity-tiering`#
