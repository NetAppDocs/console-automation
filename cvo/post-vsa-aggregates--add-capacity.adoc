= Add the capacity to an existing elastic volume aggregate
:imagesdir: ../media/

[.lead]
Adds capacity to an existing elastic volume aggregate. Use this to increase the aggregate's available storage for workloads.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/aggregates/{workingEnvironmentId}/{aggregateName}/add-capacity`#
