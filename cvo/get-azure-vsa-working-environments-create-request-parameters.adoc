= Retrieve the action parameters
:imagesdir: ../media/

[.lead]
Retrieves the action parameters used in the create request for a specific Cloud Volumes ONTAP instance. Use this to view the parameters required for creating a new instance.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/create-request-parameters`#
