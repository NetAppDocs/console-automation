= Add an iSCSI initiator
:imagesdir: ../media/

[.lead]
Adds an iSCSI initiator, defining a new initiator for iSCSI access. Use this to configure connections to storage resources.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/fsx/volumes/initiator`#

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|aliasName
|string
|True
a|Initiator alias


|iqn
|string
|True
a|Initiator IQN


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "aliasName": "string",
  "iqn": "string"
}
====

== Error

```
Status: Default, Default response
```
