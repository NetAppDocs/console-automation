= Generate a new key pair and self-signed certificate
:imagesdir: ../media/

[.lead]
Generates a new key pair and self-signed certificate at the key store. Use this to obtain a certificate signing request (CSR) for authentication workflows.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/occm/key-store`#

== Usage notes

Generates a new key pair and self-signed certificate at the key store and returns a certificate signing request (CSR).
