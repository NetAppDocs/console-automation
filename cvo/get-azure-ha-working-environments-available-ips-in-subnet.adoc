= Retrieve available IP addresses in the subnet of a system
:imagesdir: ../media/

[.lead]
Retrieves the number of available IP addresses in a Cloud Volumes ONTAP system's subnet. Use this to determine the IP address availability for network configuration or resource allocation.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}/available-ips-in-subnet`#
