= Retrieve a key manager CA certificate
:imagesdir: ../media/

[.lead]
Retrieves a specific key manager certificate authority (CA) certificate. Use this to access the certificate information for encryption or security management purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/occm/encryption/key-managers-ca-certificates/{keyManagerCaCertificateId}`#
