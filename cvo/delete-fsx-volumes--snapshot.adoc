= Delete a snapshot
:imagesdir: ../media/

[.lead]
Deletes a snapshot manually, removing the specified snapshot from the system. Use this to manage storage space or clean up outdated snapshots.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/fsx/volumes/{fileSystemId}/{svmName}/{volumeName}/snapshot`#
