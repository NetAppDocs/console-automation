= Register an extra capacity license
:imagesdir: ../media/

[.lead]
Registers an extra capacity license, enabling the system to utilize additional storage capacity. Use this to expand the available storage allocation for your Cloud Volumes ONTAP system.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/extra-capacity-licenses`#
