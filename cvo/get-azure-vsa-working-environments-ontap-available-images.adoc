= Retrieve images already installed
:imagesdir: ../media/

[.lead]
Retrieves images already installed on the Cloud Volumes ONTAP system. Use this to review the available images for deployment or management tasks.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/ontap-available-images`#
