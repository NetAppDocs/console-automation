= Retrieve supported capacity tiers for Google Cloud disk types
:imagesdir: ../media/

[.lead]
Retrieves the supported capacity tiers for Google Cloud disk types. Use this to determine the available tier options for provisioning storage resources in Google Cloud.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/metadata/supported-capacity-tiers`#
