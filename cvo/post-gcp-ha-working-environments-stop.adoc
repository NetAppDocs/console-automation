= Stop a specific Cloud Volumes ONTAP instance
:imagesdir: ../media/

[.lead]
Stops a specific Cloud Volumes ONTAP instance. Use this endpoint to halt operations on the instance when maintenance or decommissioning is required.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/stop`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|takeSnapshots
|boolean
|query
|False
a|
