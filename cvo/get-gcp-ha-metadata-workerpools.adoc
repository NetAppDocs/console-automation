= Retrieve Google Cloud worker pools for a Cloud Volumes ONTAP system
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/metadata/workerPools`#



Retrieves Google Cloud worker pools using Infrastructure Manager (IM) in which a private mode Cloud Volumes ONTAP system can be created.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|project
|string
|query
|False
a|The project ID to use for the request


|region
|string
|query
|True
a|The region in which to list worker pools


|===
