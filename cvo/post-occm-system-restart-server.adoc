= Restart the server
:imagesdir: ../media/

[.lead]
Restarts the server, initiating a reboot process to restore functionality or apply configuration changes. Use this to troubleshoot issues or complete updates requiring a restart.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/occm/system/restart-server`#

== Error

```
Status: Default, Default response
```
