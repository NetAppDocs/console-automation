= Delete a system
:imagesdir: ../media/

[.lead]
Deletes an existing Cloud Volumes ONTAP system, including all associated cloud resources unless specified otherwise. Use this to remove systems that are no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/azure/ha/working-environments/{workingEnvironmentId}`#

== Usage notes

Deletes an existing Cloud Volumes ONTAP system, including all cloud resources created for the system (unless the localDelete flag is set to true).
