= Register extra capacity licenses
:imagesdir: ../media/

[.lead]
Registers an extra capacity license, enabling the system to utilize additional storage capacity. Use this to expand available resources for your workloads.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/working-environments/{workingEnvironmentId}/extra-capacity-licenses`#
