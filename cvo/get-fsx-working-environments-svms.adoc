= Retrieve an SVM list for an FSx system
:imagesdir: ../media/

[.lead]
Retrieves an SVM list for an existing FSx system, providing the available storage virtual machines associated with the system. Use this to view and manage the SVM configurations in your FSx environment.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/fsx/working-environments/{fileSystemId}/svms`#
