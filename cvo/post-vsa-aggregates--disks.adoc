= Add disks to an existing aggregate
:imagesdir: ../media/

[.lead]
Adds disks to an existing aggregate to increase its storage capacity or improve performance. Use this endpoint to expand aggregates as your storage needs grow.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/vsa/aggregates/{workingEnvironmentId}/{aggregateName}/disks`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|aggregateName
|string
|path
|True
a|

|===
