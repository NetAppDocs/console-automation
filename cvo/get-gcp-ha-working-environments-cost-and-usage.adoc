= Retrieve the system cost and usage
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/cost-and-usage`#



Retrieves the system cost and usage.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|start
|string
|query
|False
a|

|end
|string
|query
|False
a|

|===
