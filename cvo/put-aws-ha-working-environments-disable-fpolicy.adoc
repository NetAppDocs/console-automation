= Disable FPolicy for ransomware files
:imagesdir: ../media/

[.lead]
Disables the FPolicy for ransomware files, stopping ransomware file screening on the storage system. Use this to prevent FPolicy from interfering with file access or operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/aws/ha/working-environments/{workingEnvironmentId}/disable-fpolicy`#
