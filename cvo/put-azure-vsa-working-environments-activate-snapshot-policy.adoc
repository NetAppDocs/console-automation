= Activate snapshot policy assignment
:imagesdir: ../media/

[.lead]
Activates snapshot policy assignment for unprotected read/write volumes. Use this to ensure snapshot policies are applied consistently across volumes requiring protection.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/activate-snapshot-policy`#

== Usage notes

Activates snapshot policy assignment for all unprotected read/write volumes.
