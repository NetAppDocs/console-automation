= Upload cloud license file content
:imagesdir: ../media/

[.lead]
Uploads the content of a cloud license file on the specified Cloud Volumes ONTAP system. Use this to manage licensing for your Cloud Volumes ONTAP deployment.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/upload-licenses`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|===
