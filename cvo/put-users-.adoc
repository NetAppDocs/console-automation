= Update an existing user

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/users/{userId}`#



Updates an existing user.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|userId
|string
|path
|True
a|

|===

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|firstName
|string
|False
a|The first name of the user


|lastName
|string
|False
a|The last name of the user


|email
|string
|False
a|The email address of the user


|ldapUserName
|string
|False
a|Active Directory user name


|notificationsOptIn
|boolean
|False
a|Email notifications opt-in


|===
