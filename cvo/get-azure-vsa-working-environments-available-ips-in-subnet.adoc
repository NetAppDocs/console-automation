= Retrieve the number of available IP addresses
:imagesdir: ../media/

[.lead]
Retrieves the number of available IP addresses in the Cloud Volumes ONTAP system's subnet. Use this to monitor IP address availability for network configuration or resource allocation.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/azure/vsa/working-environments/{workingEnvironmentId}/available-ips-in-subnet`#
