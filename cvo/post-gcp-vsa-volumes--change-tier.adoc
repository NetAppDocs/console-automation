= Update the underlying volume tier
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/gcp/vsa/volumes/{workingEnvironmentId}/{svmName}/{volumeName}/change-tier`#



Updates the underlying volume tier.

|Name
|Type
|In
|Required
|Description

|string

a|

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description
