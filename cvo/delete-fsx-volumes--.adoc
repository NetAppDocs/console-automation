= Delete an existing volume
:imagesdir: ../media/

[.lead]
Deletes an existing volume. Use this to remove volumes that are no longer needed or to free up storage resources.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/fsx/volumes/{fileSystemId}/{svmName}/{volumeName}`#
