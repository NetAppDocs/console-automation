= Retrieve the CIFS configuration for a system
:imagesdir: ../media/

[.lead]
Retrieves the CIFS configuration for an existing Cloud Volumes ONTAP system, providing details about the system's CIFS setup. Use this to review or verify CIFS settings for your Cloud Volumes ONTAP deployment.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/gcp/ha/working-environments/{workingEnvironmentId}/cifs`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|workingEnvironmentId
|string
|path
|True
a|

|svm
|string
|query
|False
a|

|===
