= Update NetApp Support Site key credentials
:imagesdir: ../media/

[.lead]
Updates NetApp Support Site key credentials to refresh the authentication information used for accessing NetApp services. Use this to ensure that the credentials remain valid and up to date.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/ipa/account/{accountId}/nss-key/{nssKeyId}`#

== Token usage

NetApp Console user token.

== Usage notes

Updates NetApp Support Site key credentials.
