= Create an IDaaS NetApp Support Site key credential
:imagesdir: ../media/

[.lead]
Creates an identity-as-a-service (IDaaS) NetApp Support Site key credential. Use this endpoint to generate credentials for accessing NetApp Support Site resources through the IPA service.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/ipa/account/{accountId}/idaas-key`#

== Token usage

NetApp Console user token.

== Usage notes

Creates an identity-as-a-service (IDaaS) NetApp Support Site key credential.
