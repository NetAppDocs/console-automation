= Retrieve an access token
:imagesdir: ../media/

[.lead]
Retrieves a NetApp Support Site user B2C access token, which is required for authenticating and accessing NetApp Console services.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/ipa/nss-key/{nssKeyId}/access-token`#

== Token usage

NetApp Console service token.

== Usage notes

Retrieves a NetApp Support Site user B2C access token.
