= Disassociate a resource
:imagesdir: ../media/

[.lead]
Disassociates a resource from a specified NetApp Support Site key. Use this to manage resource relationships effectively within your environment.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/ipa/account/{accountId}/nss-key/{nssKeyId}/disassociate`#

== Token usage

NetApp Console user token.

== Usage notes

Disassociates a resource from a specified NetApp Support Site key.
