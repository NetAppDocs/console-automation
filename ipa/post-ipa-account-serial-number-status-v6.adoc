= Retrieve IPA license status (v6)
:imagesdir: ../media/

[.lead]
Retrieves an IPA license status (v6), providing information about the current license configuration. Use this to verify licensing details for the IPA service.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/ipa/account/{accountId}/serial-number/{serialNumber}/status/v6`#

== Token usage

NetApp Console service token.

== Usage notes

Retrieves an IPA license status (V6).
