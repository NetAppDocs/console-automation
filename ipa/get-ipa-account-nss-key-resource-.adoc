= Retrieve NetApp Support Site credentials
:imagesdir: ../media/

[.lead]
Retrieves NetApp Support Site credentials for a specified resource ID, validating them if the validateKey field is true. Use this to confirm access credentials for integration or troubleshooting purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/ipa/account/{accountId}/nss-key/resource/{resourceId}`#

== Token usage

NetApp Console user token.

== Usage notes

Retrieves NetApp Support Site credentials for a specified resource ID and validates them if the validateKey field is true.
