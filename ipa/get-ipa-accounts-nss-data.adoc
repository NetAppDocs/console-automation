= Retrieve NetApp Support Site data for accounts
:imagesdir: ../media/

[.lead]
Retrieves NetApp Support Site data associated with NetApp Console accounts. Use this to access support-related information tied to your account.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/ipa/accounts/nss-data`#

== Token usage

NetApp Console service token.

== Usage notes

Retrieves NetApp Support Site data associated with the NetApp Console accounts.
