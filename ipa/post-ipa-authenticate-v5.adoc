= Authenticate an IPA license (v5)
:imagesdir: ../media/

[.lead]
Authenticates an IPA license (v5), verifying its validity for use with the IPA service. Use this to ensure compliance and access to licensed features.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/ipa/authenticate/v5`#

== Token usage

== Usage notes
