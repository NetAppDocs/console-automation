= Retrieve a list of KeyRings for a region
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v1/gcp/project/{projectId}/region/{locationId}/keyrings`#



Retrieves a list of KeyRings for a region from a specific Google Cloud project.

*Token usage:* NetApp Console user token.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|Account ID


|projectId
|string
|path
|True
a|Project ID


|locationId
|string
|path
|True
a|Region or location (for example, "us-east1")


|authorization
|string
|header
|True
a|User token


|X-Agent-Id
|string
|header
|True
a|Request identifier


|===
