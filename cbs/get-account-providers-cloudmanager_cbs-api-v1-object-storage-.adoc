= Retrieve buckets for a cloud provider
:imagesdir: ../media/

[.lead]
Retrieves buckets for the specified cloud provider. Use this to view and manage the storage buckets available for backup and recovery operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v1/object-storage/{provider}`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|Account ID


|provider
|string
|path
|True
a|Cloud provider type


|authorization
|string
|header
|True
a|Authorization token


|X-Agent-Id
|string
|header
|True
a|Agent ID


|===

== Response

```
Status: 200, Default Response
```
