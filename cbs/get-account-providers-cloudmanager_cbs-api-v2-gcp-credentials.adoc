= List Google Cloud credentials
:imagesdir: ../media/

[.lead]
Retrieves Google Cloud credentials in the NetApp Console SaaS application. Use this to view the credentials available for managing Google Cloud resources.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v2/gcp/credentials`#

== Token usage

NetApp Console user token.

== Usage notes

Lists Google Cloud credentials in the NetApp Console SaaS application.
