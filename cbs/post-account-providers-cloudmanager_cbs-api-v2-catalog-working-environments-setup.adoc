= Configure a service
:imagesdir: ../media/

[.lead]
Configures the service to include an indexed cataloging service, enabling integration with supported analytics and query services across AWS, Azure, Google Cloud, and StorageGRID environments. Use this to set up cataloging capabilities tailored to your cloud platform.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v2/catalog/working-environments/{workingEnvironmentId}/setup`#

== Token usage

NetApp Console user token.

== Usage notes

It enables the AWS Athena interactive S3 query service and AWS Glue serverless data integration service for AWS setup, Azure Synapse analytics service for Azure setup, Google BigQuery service for Google Cloud setup and DuckDB installation for StorageGRID.
