= Retrieve AWS keys
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v1/aws/awsAccountId/{awsAccountId}/region/{regionCode}/key`#



Retrieves a list of AWS keys from a specified region that belongs to a specified AWS account ID.

*Token usage:* NetApp Console user token.


== Parameters

[cols=5*,options=header]
|===

|Type

|Description

|string
