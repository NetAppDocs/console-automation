= Delete StorageGRID credentials
:imagesdir: ../media/

[.lead]
Deletes StorageGRID credentials in the NetApp Console SaaS application. Use this to remove credentials that are no longer needed or to revoke access to a StorageGRID instance.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v2/sg/credentials/{storageServerName}`#

== Token usage

NetApp Console user token.

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|Account ID


|storageServerName
|string
|path
|True
a|StorageGRID server name


|authorization
|string
|header
|True
a|User token


|X-Agent-Id
|string
|header
|True
a|Request identifier


|===

== Response

```
Status: 204, Default response
```
