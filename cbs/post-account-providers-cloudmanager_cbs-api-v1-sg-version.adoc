= Retrieve StorageGRID server version
:imagesdir: ../media/

[.lead]
Retrieves the version of the StorageGRID servers. Use this to verify the server version for compatibility or troubleshooting purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v1/sg/version`#

== Token usage

NetApp Console user token.
