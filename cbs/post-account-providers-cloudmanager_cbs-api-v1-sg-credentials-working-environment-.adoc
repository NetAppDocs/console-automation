= Save StorageGRID credentials
:imagesdir: ../media/

[.lead]
Saves the StorageGRID credentials, enabling authentication for accessing StorageGRID resources. Use this to securely store credentials for integration with Backup and Recovery workflows.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v1/sg/credentials/working-environment/{workingEnvironmentId}`#

== Usage notes

Saves the StorageGRID credentials.*Token usage:* NetApp Console user token.
