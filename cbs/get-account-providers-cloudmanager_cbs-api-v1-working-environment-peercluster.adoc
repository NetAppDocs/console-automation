= Retrieve a list of ONTAP clusters peered to a system
:imagesdir: ../media/

[.lead]
Retrieves a list of ONTAP clusters peered to a specific system. Use this to view the clusters associated with the specified system ID.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v1/working-environment/{workingEnvironmentId}/peercluster`#

== Token usage

NetApp Console user token.

== Usage notes

The required system ID is passed as a parameter for the API call.
