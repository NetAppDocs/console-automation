= Verify the valid licenses in a system
:imagesdir: ../media/

[.lead]
Retrieves the valid licenses in a system, verifying the marketplace subscription, backup license, and SnapMirror license status. Use this to confirm license validity for backup and recovery operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v1/license/working-environment/{workingEnvironmentId}/validity`#

== Token usage

NetApp Console user token.

== Usage notes

Checks if there is a valid marketplace subscription, backup license, and SnapMirror license in a system.
