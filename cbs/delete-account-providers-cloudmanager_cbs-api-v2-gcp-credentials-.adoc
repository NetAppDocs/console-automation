= Delete Google Cloud credentials
:imagesdir: ../media/

[.lead]
Deletes Google Cloud credentials for a Google Cloud project in the NetApp Console SaaS application. Use this to remove credentials that are no longer needed or require replacement.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/account/{accountId}/providers/cloudmanager_cbs/api/v2/gcp/credentials/{credentialsId}`#

== Token usage

NetApp Console user token.
