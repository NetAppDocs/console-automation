= Add AWS credentials
:imagesdir: ../media/

[.lead]
Creates AWS credentials for the FSx for ONTAP service. Use this to establish access permissions for AWS resources.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/aws-credentials/{accountId}`#

== Token usage

Cloud Manager user token.

== Usage notes

DEPRECATED Create AWS Credentials


CAUTION: This operation is deprecated.
