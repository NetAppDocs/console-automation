= Retrieve AWS credentials
:imagesdir: ../media/

[.lead]
Retrieves AWS credentials for a specific tenancy account. Use this to access and manage tenancy-specific authentication details.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/aws-credentials/{accountId}`#

== Token usage

Cloud Manager user token.

== Usage notes

Retrieves all the AWS credentials for a specific tenancy account.
