= Retrieve VPCs
:imagesdir: ../media/

[.lead]
Retrieves all VPCs by region using the specified credentials. Use this to view the available VPCs in a particular region.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/aws/vpcs`#

== Token usage

Cloud Manager user token.

== Usage notes

Retrieves all VPCs by region by using the credentials.
