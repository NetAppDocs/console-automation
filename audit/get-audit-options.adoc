= Retrieve audit options
:imagesdir: ../media/

[.lead]
Retrieves audit filter options for a specified account ID. Use this to view the available filters for auditing activities.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/audit/{accountId}/options`#

== Token usage

NetApp Console user token.

== Usage notes

Retrieves filter options by a specified account ID.

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|

|===
