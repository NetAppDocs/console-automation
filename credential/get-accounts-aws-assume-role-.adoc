= Retrieve credentials using the ID
:imagesdir: ../media/

[.lead]
Retrieves existing ARN credentials using the specified account public ID. Use this to access the credentials associated with an account for authentication or authorization purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{accountPublicId}/aws/assume-role/{credentialsId}`#

== Token usage

Both a NetApp Console user token and service token. The service token needs to include the following scopes: credentials:internal. Pass the user token or service token in the Authorization request header.
