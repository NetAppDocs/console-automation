= Generate token from ID
:imagesdir: ../media/

[.lead]
Generates an Azure token using existing service principal credentials. Use this to authenticate requests with a NetApp Console user token or service token.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{accountPublicId}/azure/service-principal/{credentialsId}/generate-token`#

== Token usage

Both a NetApp Console user token and service token. The service token needs to include the following scopes: credentials:internal. Pass the user token or service token in the Authorization request header.

== Usage notes

Generates an Azure token by using existing service principal credentials.
