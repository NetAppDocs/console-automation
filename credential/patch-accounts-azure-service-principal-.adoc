= Update service principal credentials
:imagesdir: ../media/

[.lead]
Updates service principal credentials associated with the specified account public ID. Use this to manage authentication details for service principals in your account.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/accounts/{accountPublicId}/azure/service-principal/{credentialsId}`#

== Token usage

NetApp Console user token.

== Usage notes

Updates existing credentials using the specified account public ID.
