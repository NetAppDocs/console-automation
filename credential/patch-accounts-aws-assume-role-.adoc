= Update credentials
:imagesdir: ../media/

[.lead]
Updates existing credentials associated with a specified account public ID. Use this to modify account credentials as needed for authentication or access management.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/accounts/{accountPublicId}/aws/assume-role/{credentialsId}`#

== Token usage

NetApp Console user token.

== Usage notes

Updates existing credentials using the specified account public ID.
