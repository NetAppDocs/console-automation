= Retrieve credentials by ID
:imagesdir: ../media/

[.lead]
Retrieves an existing service principal by its account public ID. Use this to access details about a specific service principal for authentication or authorization purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{accountPublicId}/azure/service-principal/{credentialsId}`#

== Token usage

Both a NetApp Console user token and service token. The service token needs to include the following scopes: credentials:internal. Pass the user token or service token in the Authorization request header.

== Usage notes

Retrieves an existing service principal using the specified account public ID.
