= Retrieve user and service account data
:imagesdir: ../media/

[.lead]
Retrieves the user and service account data of the specified account. Use this to access account-specific information for management or troubleshooting purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/tenancy/account/{accountId}/members`#

== Token usage

BlueXP user token.

== Usage notes

Retrieves the user and service account data of the specified account.
