= Retrieve user data
:imagesdir: ../media/

[.lead]
Retrieves the user data of a specified account. Use this to access account-specific information for tenancy management tasks.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/tenancy/account/{accountId}/users`#

== Token usage

BlueXP user token.

== Usage notes

Retrieves the user data of the specified account.
