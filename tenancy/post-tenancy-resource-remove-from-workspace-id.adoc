= Remove a resource from a workspace
:imagesdir: ../media/

[.lead]
Deletes a resource from a specified workspace. Use this to manage workspace resources by removing unneeded items.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/tenancy/resource/{resourceIdentifier}/remove-from-workspace/{workspacePublicId}`#

== Token usage

BlueXP user token.

== Usage notes

Removes a resource from a specified workspace.

== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|resourceIdentifier
|string
|path
|True
a|* example: VsaWorkingEnvironment-yQFegzgz


|workspacePublicId
|string
|path
|True
a|* example: workspace-APWLzah1


|authorization
|string
|header
|True
a|Authorization JWT access token


|X-User-Token
|string
|header
|False
a|User JWT access token


|X-Service-Request-Id
|string
|header
|False
a|Request identifier

|===

== Response

```
Status: 200, Default response
```
