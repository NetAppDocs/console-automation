= Retrieve service account data
:imagesdir: ../media/

[.lead]
Retrieves the service account data for a specified account. Use this to access detailed information about the account for management or audit purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/tenancy/account/{accountId}/service-accounts`#

== Token usage

BlueXP user token.

== Usage notes

Retrieves the service account data of the specified account.
