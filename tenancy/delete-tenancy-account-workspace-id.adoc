= Delete a workspace
:imagesdir: ../media/

[.lead]
Deletes a specified workspace. Use this endpoint to remove workspaces that are no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/tenancy/account/{accountId}/workspace/{workspacePublicId}`#

== Token usage

BlueXP user token.

== Usage notes

Deletes a specified workspace.
