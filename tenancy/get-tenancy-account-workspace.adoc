= Retrieve workspaces
:imagesdir: ../media/

[.lead]
Retrieves workspaces associated with a specified account. Use this to view the workspaces linked to your account.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/tenancy/account/{accountId}/workspace`#

== Token usage

BlueXP user token.

== Usage notes

Retrieves workspaces associated with a specified account.
