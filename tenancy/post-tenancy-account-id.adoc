= Create an account
:imagesdir: ../media/

[.lead]
Creates an account with the specified account name. Use this to establish a new account in the tenancy service for managing resources.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/tenancy/account/{accountName}`#

== Token usage

BlueXP user token.

== Usage notes

Creates a new account with the specified account name.

== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|accountName
|string
|path
|True
a|Account name

* pattern: {caret}[-_.a-zA-Z0-9]{1,40}$


|authorization
|string
|header
|True
a|Authorization JWT access token


|X-User-Token

|X-Service-Request-Id
