= Generate a secret
:imagesdir: ../media/

[.lead]
Generates a service account secret for use in authenticating requests. Use this to manage access credentials securely within your tenancy.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/tenancy/account/{accountId}/service-account/{serviceAccountId}/generate-service-account-secret`#

== Token usage

BlueXP user token.

== Usage notes

Generates the service account secret.

== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|

|serviceAccountId
|string
|path
|True
a|Service Account Client ID. Do not provide the Service Account Public ID.

* example: BjwDgGkg28cLKg70pLUwz9rY87Ff5xHK


|authorization
|string
|header
|True
a|Authorization JWT access token


|X-User-Token
|string
|header
|False
a|User JWT access token


|X-Service-Request-Id
|string
|header
|False
a|Request identifier

|===
