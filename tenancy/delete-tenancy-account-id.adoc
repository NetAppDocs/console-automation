= Delete an account
:imagesdir: ../media/

[.lead]
Deletes the specified account. Use this operation to remove an account that is no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/tenancy/account/{accountId}`#

== Token usage

BlueXP user token.

== Usage notes

Deletes the specified account.
