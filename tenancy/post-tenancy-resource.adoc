= Create an external resource
:imagesdir: ../media/

[.lead]
Creates an external resource as a BlueXP resource. Use this endpoint to register a resource with the specified type in BlueXP.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/tenancy/resource`#

== Token usage

BlueXP user token.

== Usage notes

Creates an external resource as a BlueXP resource. resourceType must be passed to the request.

== Parameters

[cols=5*,options=header]

|Name
|Type
|In
|Required
|Description

|string

|True

|X-Service-Request-Id
|string
|header
|False
a|Request identifier

|===
