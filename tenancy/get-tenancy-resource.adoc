= Retrieve a resource
:imagesdir: ../media/

[.lead]
Retrieves a resource for an account. Use this to access the resource details associated with a specific account.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/tenancy/resource`#

== Token usage

BlueXP user token.

== Usage notes

Retrieves a resource for an account.
