= Remove an agent
:imagesdir: ../media/

[.lead]
Deletes an agent from a specified workspace. Use this to manage the agents associated with your workspaces.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/tenancy/account/{accountId}/workspace/{workspacePublicId}/remove-agent/{agentAuth0Id}`#

== Token usage

BlueXP user token.

== Usage notes

Removes an agent from a specified workspace.
