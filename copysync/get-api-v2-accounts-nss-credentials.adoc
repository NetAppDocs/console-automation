= Retrieve NetApp support site credentials
:imagesdir: ../media/

[.lead]
Retrieves the NetApp Support Site credentials, providing access to support resources and services.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/v2/accounts/{accountId}/nss-credentials`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
