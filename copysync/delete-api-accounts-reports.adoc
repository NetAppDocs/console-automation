= Delete the reports by a specified report ID
:imagesdir: ../media/

[.lead]
Deletes reports by a specified report ID. Use this endpoint to remove report data that is no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/api/accounts/{accountId}/reports`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|reports
|array[]
|query
|True
a|Reports IDs to delete


|accountId
|string
|path
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
