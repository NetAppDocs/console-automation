= Retrieve the storage type
:imagesdir: ../media/

[.lead]
Retrieves the storage type, providing information about the available storage configurations. Use this to determine the appropriate storage type for your operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/storages/{protocol}`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|provider
|string
|query
|False
a|Provider


|protocol
|string
|path
|True
a|

|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
