= Retrieve all relationships
:imagesdir: ../media/

[.lead]
Retrieves all relationships, providing details about the existing connections and their configurations. Use this to review relationship data for synchronization or management purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/relationships-v2`#

|Name
|Type

|Required
|Description

|string
|header
|True
a|NetApp tenancy account ID


|===
