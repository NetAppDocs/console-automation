= Retrieve the Google Cloud buckets
:imagesdir: ../media/

[.lead]
Retrieves the Google Cloud buckets accessible from a NetApp data broker. Use this to view the available buckets for data copy and sync operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/data-brokers/{id}/list-gcp-buckets`#


CAUTION: This operation is deprecated.

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|id
|string
|path
|True
a|Data Broker ID


|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 202, Default Response
```
