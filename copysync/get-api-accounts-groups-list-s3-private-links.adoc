= Retrieve the S3 private links
:imagesdir: ../media/

[.lead]
Retrieves the S3 private links, providing access to information about private links for S3 resources. Use this to identify and manage private connectivity to your S3 endpoints.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/groups/{id}/list-s3-private-links`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|region
|string
|query
|True
a|AWS region


|accountId
|string
|path
|True
a|NetApp tenancy account ID


|id
|string
|path
|True
a|Data Brokers Group ID


|x-bucket-name
|string
|header
|False
a|S3 bucket- for UI use


|===

== Response

```
Status: 202, Default Response
```
