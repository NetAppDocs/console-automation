= Stop the relationship data sync
:imagesdir: ../media/

[.lead]
Stops a relationship data sync to interrupt the ongoing synchronization of data between connected systems. Use this to halt data transfer if adjustments or troubleshooting are required.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/api/relationships/{id}/abort`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|id
|string
|path
|True
a|Relationship ID


|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 202, Default Response
```
