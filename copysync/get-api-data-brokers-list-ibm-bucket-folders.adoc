= Retrieve the IBM bucket folders
:imagesdir: ../media/

[.lead]
Retrieves the IBM bucket folders from a NetApp data broker. Use this to view the folder structure for data synchronization or transfer operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/data-brokers/{id}/list-ibm-bucket-folders`#


CAUTION: This operation is deprecated.
