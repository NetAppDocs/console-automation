= Delete a license serial number
:imagesdir: ../media/

[.lead]
Deletes a license serial number, removing the serial number from the system's license records. Use this to manage license allocations or revoke unused licenses.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/api/accounts/{accountId}/licenses-v2/{serialNumber}`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|NetApp tenancy account ID


|serialNumber
|string
|path
|True
a|License Serial Number


|===

== Response

```
Status: 200, Default Response
```
