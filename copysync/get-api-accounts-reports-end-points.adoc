= Retrieve a list of the reports endpoints
:imagesdir: ../media/

[.lead]
Retrieves a list of report endpoints in the Console Copy and Sync service.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/reports/end-points`#

== Usage notes

Retrieves a list of the reports endpoints.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
