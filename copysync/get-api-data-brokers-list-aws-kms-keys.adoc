= Retrieve the AWS KMS keys
:imagesdir: ../media/

[.lead]
Retrieves the AWS KMS keys from a NetApp data broker. Use this to view the keys available for encryption operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/data-brokers/{id}/list-aws-kms-keys`#


CAUTION: This operation is deprecated.

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|bucket
|string
|query
|True
a|AWS Bucket


|id
|string
|path
|True
a|Data Broker ID


|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

Status: 202, Default Response
