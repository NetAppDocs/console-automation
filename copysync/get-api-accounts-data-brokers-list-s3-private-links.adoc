= Retrieve the S3 private links
:imagesdir: ../media/

[.lead]
Retrieves the S3 private links, providing the information needed to access private endpoints for S3 services.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/data-brokers/{id}/list-s3-private-links`#


CAUTION: This operation is deprecated.

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|region
|string
|query
|True
a|AWS region


|accountId
|string
|path
|True
a|NetApp tenancy account ID


|id
|string
|path
|True
a|Data Broker ID


|x-bucket-name
|string
|header
|False
a|S3 bucket- for UI use


|===

Status: 202, Default Response
