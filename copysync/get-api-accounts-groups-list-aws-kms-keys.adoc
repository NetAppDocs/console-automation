= Retrieve the AWS KMS keys
:imagesdir: ../media/

[.lead]
Retrieves the AWS KMS keys from a NetApp data broker. Use this to access the encryption keys required for securing data operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/groups/{id}/list-aws-kms-keys`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|bucket
|string
|query
|True
a|Bucket


|accountId
|string
|path
|True
a|NetApp tenancy account ID


|id
|string
|path
|True
a|Data Brokers Group ID


|===

== Response

```
Status: 202, Default Response
```
