= Retrieve a list of all reports
:imagesdir: ../media/

[.lead]
Retrieves a list of all reports. Use this to view the available reports for monitoring or analysis purposes.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/reports`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
