= Retrieve the ONTAP S3 buckets
:imagesdir: ../media/

[.lead]
Retrieves the ONTAP S3 buckets accessible from a NetApp data broker. Use this to view the available buckets for storage operations or data management tasks.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/groups/{id}/list-ontap-s3-buckets`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|host
|string
|query
|True
a|ONTAP S3 hostname or IP


|port
|number
|query
|False
a|Server port


|accountId
|string
|path
|True
a|NetApp tenancy account ID


|id
|string
|path
|True
a|Data Brokers Group ID


|access-key
|string
|header
|True
a|StorageGRID server access-key


|secret-key
|string
|header
|True
a|StorageGRID server secret-key


|===

== Response

```
Status: 202, Default Response
```
