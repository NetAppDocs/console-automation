= Restart a data broker
:imagesdir: ../media/

[.lead]
Restarts a data broker to reinitialize its operations or resolve issues affecting its performance. Use this endpoint when you need to restore the data broker to a functional state.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/api/accounts/{accountId}/data-brokers/{id}/restart`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|NetApp tenancy account ID


|id
|string
|path
|True
a|Data Broker ID


|===

== Response

```
Status: 202, Default Response
```
