= Download the data broker group logs
:imagesdir: ../media/

[.lead]
Downloads the data broker group logs, providing access to logs for monitoring or troubleshooting operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/api/groups/{id}/download-data-brokers-logs`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|id
|string
|path
|True
a|Data Broker Group ID


|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 202, Default Response
```
