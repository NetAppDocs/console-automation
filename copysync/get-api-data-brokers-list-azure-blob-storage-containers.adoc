= Retrieve the Azure blob storage containers
:imagesdir: ../media/

[.lead]
Retrieves the Azure blob storage containers. Use this to view the available containers for data storage and management in Azure.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/data-brokers/{id}/list-azure-blob-storage-containers`#


CAUTION: This operation is deprecated.

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|storageAccountName
|string
|query
|True
a|Azure storage account name


|id
|string
|path
|True
a|Data Broker ID


|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|storage-account-connection-string
|string
|header
|True
a|Azure storage account connection-string


|===

== Response

```
Status: 202, Default Response
```
