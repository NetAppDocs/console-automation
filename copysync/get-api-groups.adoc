= Retrieve all groups
:imagesdir: ../media/

[.lead]
Retrieves all data broker groups, providing the available group configurations for managing data broker resources. Use this to review the current groups defined in your environment.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/groups`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
