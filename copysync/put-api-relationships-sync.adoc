= Initiate a relationship data sync
:imagesdir: ../media/

[.lead]
Initiates a relationship data sync, transferring data between systems to maintain synchronization. Use this to ensure consistency across related datasets.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/api/relationships/{id}/sync`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|id
|string
|path
|True
a|Relationship ID


|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 202, Default Response
```
