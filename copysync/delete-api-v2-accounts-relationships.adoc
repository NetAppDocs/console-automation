= Delete relationships
:imagesdir: ../media/

[.lead]
Deletes relationships. Use this endpoint to remove existing relationships when they are no longer required.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/api/v2/accounts/{accountId}/relationships`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|relationships
|array[]
|query
|True
a|Relationship IDs to delete


|accountId
|string
|path
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 204, Default Response
```
