= Retrieve the StorageGRID buckets
:imagesdir: ../media/

[.lead]
Retrieves the StorageGRID buckets accessible from a NetApp data broker. Use this to view the buckets available for data management operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/data-brokers/{id}/list-sgws-buckets`#


CAUTION: This operation is deprecated.
