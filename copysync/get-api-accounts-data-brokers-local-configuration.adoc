= Retrieve the data broker local configuration
:imagesdir: ../media/

[.lead]
Retrieves the data broker local configuration, providing the current settings for local data transfer operations.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/data-brokers/{id}/local-configuration`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|accountId
|string
|path
|True
a|NetApp tenancy account ID


|id
|string
|path
|True
a|Data Broker ID


|===

== Response

```
Status: 202, Default Response
```
