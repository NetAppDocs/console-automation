= Delete the current account
:imagesdir: ../media/

[.lead]
Deletes the current account. Use this to remove an account from the Copy and Sync API when it is no longer needed.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/api/accounts`#

== Usage notes

WARNING: This action will delete the current account from the Copy and Sync API.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
