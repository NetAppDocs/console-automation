= Retrieve the StorageGRID bucket folders
:imagesdir: ../media/

[.lead]
Retrieves the StorageGRID bucket folders from a NetApp data broker, providing access to the folder structure within the bucket. Use this to review or manage folder configurations in StorageGRID.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/data-brokers/{id}/list-sgws-bucket-folders`#


CAUTION: This operation is deprecated.
