= Retrieve the Azure Data Lake Gen2 storage container folders
:imagesdir: ../media/

[.lead]
Retrieves the Azure Data Lake Gen2 storage container folders. Use this to view the folder structure within a specified storage container.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/groups/{id}/list-azure-dataLake-storage-container-folders`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|storageAccountName
|string
|query
|True
a|Azure storage account name


|container
|string
|query
|True
a|Container


|path
|string
|query
|False
a|Path inside the container, to list folders in


|accountId
|string
|path
|True
a|NetApp tenancy account ID


|id
|string
|path
|True
a|Data Brokers Group ID


|storage-account-connection-string
|string
|header
|True
a|Azure storage account connection-string


|===

== Response

```
Status: 202, Default Response
```
