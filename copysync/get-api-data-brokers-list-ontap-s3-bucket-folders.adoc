= Retrieve the ONTAP S3 bucket folders
:imagesdir: ../media/

[.lead]
Retrieves the ONTAP S3 bucket folders from a NetApp data broker. Use this to view the available folder structures within the specified S3 bucket.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/data-brokers/{id}/list-ontap-s3-bucket-folders`#


CAUTION: This operation is deprecated.
