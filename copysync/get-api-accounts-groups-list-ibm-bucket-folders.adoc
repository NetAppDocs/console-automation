= Retrieve the IBM bucket folders
:imagesdir: ../media/

[.lead]
Retrieves the IBM bucket folders from a NetApp data broker, providing access to folder information for data management tasks.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/api/accounts/{accountId}/groups/{id}/list-ibm-bucket-folders`#
