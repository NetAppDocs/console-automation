= Delete an existing NetApp data broker
:imagesdir: ../media/

[.lead]
Deletes an existing NetApp data broker. Use this endpoint to remove a data broker that is no longer needed for your environment or workflows.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/api/data-brokers/{id}`#

== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|id
|string
|path
|True
a|Data Broker ID


|x-account-id
|string
|header
|True
a|NetApp tenancy account ID


|===

== Response

```
Status: 200, Default Response
```
